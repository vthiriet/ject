# Lexique — Ject

## Objets
- **Carte** : objet affiché dans la grille. Deux types : **carte texte** et **carte liste**.
- **Carte texte** : carte dont le contenu est du texte libre.
- **Carte liste** : carte dont le contenu est une suite d'éléments.
- **Élément** : une ligne d'une carte liste, qu'on peut cocher.

## Couleurs de cartes
- **Papier** : la couleur neutre (blanc en clair, brun foncé en sombre). Les autres : Soleil, Pêche, Pistache, Lagon, Ciel, Lilas.

## Mots à éviter
- **Note** : remplacé par « carte » (ou « carte texte »). Le composant `NoteCard` sera renommé.
- **Élément** pour désigner une carte entière (ex. dans l'Inbox) : dire « carte ».
- **Blanc** pour la couleur neutre : dire « Papier ».
